# Ручная проверка Postman

Статус: не выполнена; Postman установлен, но в доступной среде нет управления его графическим интерфейсом. Результаты автоматических запросов не являются подтверждением в Postman.

Настроить в Postman базовый URL `https://qa-scooter.praktikum-services.ru`, заголовки `Content-Type: application/json` и `Accept: application/json`, конечный таймаут ответа. Использовать только новые синтетические данные.

| Проверка | Запрос и ожидаемый результат | Статус |
|---|---|---|
| CC-01 | POST `/api/v1/courier`, полный JSON: 201 и `ok: true` | Не выполнено |
| CC-02, CC-03 | Повторить создание с тем же логином, затем с другим паролем и именем: 409 и точное `message` | Не выполнено |
| CC-04, CC-05, CC-06 | Создать курьера без ключа `login`, `password`, `firstName` соответственно: 400 и точное `message`. Для CC-06 при 201 проверить `ok` и удалить курьера | Не выполнено |
| CL-01–CL-06 | Вход корректный, без каждого из обязательных ключей, с неверным логином, неверным паролем и новой парой: 200/400/400/404/404/404 и тело по контракту | Не выполнено |
| OC-01–OC-04 | POST `/api/v1/orders` с BLACK, GREY, обоими цветами и без ключа color: 201, положительный целый `track`; затем отмена | Не выполнено |
| OL-01 | GET `/api/v1/orders?limit=10&page=0`: 200, `orders` — массив | Не выполнено |
| Очистка | Получить собственный ID через login; DELETE `/api/v1/courier/{id}`; отменить собственный заказ через PUT `/api/v1/orders/cancel` с `track`; проверить 200 и `ok: true` | Не выполнено |

При таймауте CL-03 записать его длительность и отдельно различать 504 и отсутствие ответа. Не заменять отсутствующий ключ пустой строкой. Не сохранять пароли или чужую выдачу в общедоступных материалах.
