# Sprint_7 — API Самоката

Автотесты учебного API: Java 11, Maven, JUnit 4, REST Assured, Jackson и Allure 2. Четыре класса содержат 17 независимых запусков, включая четыре параметра цвета заказа. Проверяемый стенд: https://qa-scooter.praktikum-services.ru. Данные синтетические и генерируются заново для каждого запуска.

Запуск под JDK 11:

```bash
java -version
mvn -version
mvn clean test
mvn allure:report
```

Команду генерации отчёта нужно выполнить даже после неуспешных тестов и без промежуточного `clean`. Результаты находятся в `target/allure-results/`, HTML — в `target/site/allure-maven/index.html`. Открывайте HTML через локальный HTTP-сервер, например `python3 -m http.server 8000 --directory target/site/allure-maven`, затем `http://localhost:8000/`. В репозиторий включаются только сырые результаты Allure; другие файлы `target` игнорируются.

Адрес и таймауты можно изменить без правки тестов:

```bash
mvn clean test -Dscooter.baseUrl=https://example.test -Dscooter.connectTimeout=5000 -Dscooter.readTimeout=15000
```

Таймауты задаются в миллисекундах. Ручная матрица и статус Postman: [docs/postman-checklist.md](docs/postman-checklist.md). Курьеры удаляются по ID, заказы отменяются по полученному треку; при 400 на документированный JSON отмена диагностически повторяется с тем же треком также в query. При невозможности подтвердить очистку тест сообщает известные идентификаторы.

## Результат проверки стенда 16 ноября 2026

Последний чистый прогон на Microsoft OpenJDK 11.0.32.1: Surefire 17, прошло 11, failures 3, errors 3, пропущено 0; Allure: passed 11, failed 3, broken 3. Postman-подтверждения нет.

- CC-02 и CC-03: ожидалось 409 и `Этот логин уже используется`, получено 409 и `Этот логин уже используется. Попробуйте другой.`
- CC-06: ожидалось 400 и `Недостаточно данных для создания учетной записи`, получено 201 и `ok: true`; курьер удалён.
- CL-03: ожидалось 400 и `Недостаточно данных для входа`, HTTP-ответ не получен, чтение прервано таймаутом через 15,124 с. Курьер удалён.
- OL-01: ожидалось 200 и массив `orders`, HTTP-ответ не получен из-за таймаута чтения.
- OC-01: создание прошло, отмена без query вернула 400, повтор с query завершился таймаутом. Для track 414727 последующая проверка `/orders/track?t=414727` вернула 404, повторная отмена — 409 `Заказ нельзя завершить`. Очистка не подтверждена.

В первом полном прогоне OC-01 не получил ответ создания; метка `qa-6ea8f126430e4824`, трек неизвестен, очистка не подтверждена. Для OC-02, OC-03 и OC-04 создание прошло, но документированная отмена вернула 400 `Недостаточно данных для поиска`. В той версии теста треки трёх заказов не выводились при ошибке, поэтому отдельно определить и отменить эти записи теперь нельзя; очистка каждого из трёх заказов не подтверждена. В последнем прогоне OC-02–OC-04 отменены через query после ответа 400 на запрос с JSON. Все курьеры последнего прогона очищены.
